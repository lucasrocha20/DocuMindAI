# API reference

Base URL in local development: `http://localhost:3000`. All responses are JSON.

An interactive OpenAPI page (Swagger UI) is served at **`/docs`** (raw spec at `/docs-json`) while `NODE_ENV` is not `production`. It documents the invoices endpoints in full. Set `ENABLE_SWAGGER=true` to keep it on in production.

## Conventions

- **No authentication yet.** Anyone who can reach the API can use every endpoint. See [Limitations](../README.md#limitations).
- **Money and quantities are strings** with fixed decimals (`"1284.00"`, `"2.500"`), so no precision is lost to floating point. Parse them with a decimal library, or `Number()` for display only.
- **Dates:** `issueDate` is a calendar date (`YYYY-MM-DD`); timestamps are ISO 8601 in UTC.
- **IDs** are UUIDs. A malformed id is a `400`, an unknown one a `404`.
- **Rate limits**, per client IP: 300 requests per minute per route, and 10 uploads per minute. Over the limit you get `429` with a `Retry-After` header. `/health` is never limited.
- **Errors** share one shape:

  ```json
  { "message": "Invoice not found", "error": "Not Found", "statusCode": 404 }
  ```

  `message` is a string, or an array of `"field: reason"` strings for query validation errors.

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| `GET` | `/health` | Liveness check |
| `POST` | `/documents/upload` | Upload a PDF for processing |
| `GET` | `/documents` | List uploads with their processing status |
| `GET` | `/documents/:id` | One upload |
| `GET` | `/invoices` | List extracted invoices (paginated, filterable) |
| `GET` | `/invoices/:id` | One invoice with its line items |

### `GET /health`

```json
{ "status": "ok", "timestamp": "2026-09-21T00:13:42.170Z" }
```

### `POST /documents/upload`

`multipart/form-data` with exactly one part, a file named **`file`**. Only real PDFs are accepted (the content is checked, not the filename or the declared type), up to **10 MB**.

```bash
curl -F "file=@invoice.pdf;type=application/pdf" http://localhost:3000/documents/upload
```

`201 Created` returns the new document, always `PENDING`. Processing continues in the background:

```json
{
  "id": "497e67c0-56f6-4bc8-9045-e61315a0a488",
  "filename": "invoice.pdf",
  "status": "PENDING",
  "errorMessage": null,
  "invoiceId": null,
  "createdAt": "2026-09-21T00:09:00.759Z",
  "updatedAt": "2026-09-21T00:09:00.759Z"
}
```

| Status | When | `message` |
|---|---|---|
| `400` | File sent under another field name | `Unexpected file field` |
| `400` | Any extra form field or second file | `Too many fields` / `Too many files` |
| `413` | Over 10 MB | `File too large` |
| `422` | Content is not a PDF | `The uploaded file is not a valid PDF.` |
| `422` | No file attached | `File is required` |
| `429` | More than 10 uploads a minute from one IP | `ThrottlerException: Too Many Requests` |
| `500` | The job could not be queued (the document is kept, marked `FAILED`) | `Failed to queue document for processing` |

The stored filename is generated by the server; `filename` in responses is the sanitised original name, for display only.

### `GET /documents`

The 100 most recent uploads, newest first (there is no pagination).

```json
[
  {
    "id": "eb8a2aaa-0edd-40df-9441-45118f7bba35",
    "filename": "harbor-vine-0412.pdf",
    "status": "COMPLETED",
    "errorMessage": null,
    "invoiceId": "528d09e8-d22f-42d6-91e2-d7e5417929a1",
    "createdAt": "2026-09-20T20:59:01.375Z",
    "updatedAt": "2026-09-20T23:59:01.375Z"
  },
  {
    "id": "90703bd6-07b0-4e97-bb1a-b70c53bf6a86",
    "filename": "scan-0012.pdf",
    "status": "FAILED",
    "errorMessage": "No extractable text was found in this PDF. It may be a scanned or image-based document, which is not supported yet.",
    "invoiceId": null,
    "createdAt": "2026-09-20T23:19:01.385Z",
    "updatedAt": "2026-09-20T23:59:01.385Z"
  }
]
```

`status` is one of `PENDING`, `PROCESSING`, `COMPLETED`, `FAILED`. `errorMessage` is only set for `FAILED` and is always safe to show to a user. `invoiceId` is set once an invoice has been extracted.

### `GET /documents/:id`

One document, in the same shape. `404` if it does not exist.

### `GET /invoices`

Newest first.

| Query | Default | Notes |
|---|---|---|
| `page` | `1` | Integer, 1 or more. A page past the end returns an empty `data` array, not an error |
| `pageSize` | `20` | Integer, 1 to 100 |
| `supplierName` | none | Case-insensitive partial match. A blank value means no filter |
| `invoiceNumber` | none | Case-insensitive partial match. A blank value means no filter |

Characters like `%` and `_` in filters match literally.

```bash
curl "http://localhost:3000/invoices?supplierName=harbor&pageSize=10"
```

```json
{
  "data": [
    {
      "id": "528d09e8-d22f-42d6-91e2-d7e5417929a1",
      "documentId": "eb8a2aaa-0edd-40df-9441-45118f7bba35",
      "supplierName": "Harbor & Vine Catering",
      "invoiceNumber": "HV-2026-0412",
      "issueDate": "2026-09-12",
      "totalAmount": "1284.00",
      "currency": "EUR",
      "createdAt": "2026-09-20T20:59:01.375Z"
    }
  ],
  "meta": { "page": 1, "pageSize": 10, "total": 1, "totalPages": 1 }
}
```

Invalid parameters return `400` with every problem listed:

```json
{
  "message": [
    "page: Too small: expected number to be >=1",
    "pageSize: Too big: expected number to be <=100"
  ],
  "error": "Bad Request",
  "statusCode": 400
}
```

### `GET /invoices/:id`

The summary fields plus `updatedAt` and the line items, **in the order they appear on the invoice**.

```json
{
  "id": "528d09e8-d22f-42d6-91e2-d7e5417929a1",
  "documentId": "eb8a2aaa-0edd-40df-9441-45118f7bba35",
  "supplierName": "Harbor & Vine Catering",
  "invoiceNumber": "HV-2026-0412",
  "issueDate": "2026-09-12",
  "totalAmount": "1284.00",
  "currency": "EUR",
  "createdAt": "2026-09-20T20:59:01.375Z",
  "updatedAt": "2026-09-20T23:59:01.375Z",
  "items": [
    { "description": "Buffet lunch, 40 guests", "quantity": "40.000", "unitPrice": "24.00", "totalPrice": "960.00" },
    { "description": "Coffee and pastry service", "quantity": "1.000", "unitPrice": "180.00", "totalPrice": "180.00" },
    { "description": "Venue setup", "quantity": "1.000", "unitPrice": "144.00", "totalPrice": "144.00" }
  ]
}
```

The invoice total is what the document states; it is not recomputed from the items.

The raw AI output stored in the database and the internal file location are never returned.
